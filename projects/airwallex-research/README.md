# Airwallex 调研报告版本说明

本目录保留三份主报告，分别用于不同发布场景：

1. `Airwallex全球调研报告.md`：原始无插图版，只保留正文、表格和参考资料，不包含任何 Markdown 图片引用。
2. `Airwallex全球调研报告-SVG插图版.md`：SVG 数据图表版，使用 `assets/charts/` 下的可复现 SVG 图表。
3. `Airwallex全球调研报告-ImageGen-PNG插图版.md`：ImageGen PNG 信息图版，主要引用 `gpt-image-2-infographics-20260522-0536/images/` 下的 16:9 PNG 图片。

## 资产目录

- `assets/charts/`：SVG 数据图表，适合强调数据准确性和可维护性。
- `gpt-image-2-infographics-20260522-0536/images/`：ImageGen 生成的 16:9 PNG 信息图，适合增强报告视觉呈现和主题解释。
- `gpt-image-2-showcase-20260522-050042/images/`：早期 ImageGen PNG 展示图留档。
- `gpt-image-2-showcase-20260522-050042/prompts/`：早期 PNG 展示图提示词留档。

## 留档文件

`gpt-image-2-showcase-20260522-050042/Airwallex全球调研报告-混合插图留档-20260522-050042.md` 是曾经同时包含 SVG 和 PNG 的中间版本，仅用于追溯，不作为主报告入口。
