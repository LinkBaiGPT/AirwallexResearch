5. `airwallex-infographic-product-stack.png`：从资金入口到全球金融操作系统的产品路径。

## 使用说明

- 生成模式：内置 `image_gen`。
- 图片比例：16:9 横版，实际尺寸为 1672 x 941。
- 设计方向：现代极简 UI、浅色背景、白色卡片、教育类信息图。
- 数据口径：图片用于辅助阅读和视觉表达，准确数据以报告正文和 SVG 图表为准。
